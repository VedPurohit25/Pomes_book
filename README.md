# 🪷 Whispers of the Indian Wind — 3D Interactive Poetry Anthology

An interactive, 3D flipbook application showcasing classic masterpieces of Indian poetry. Built using modern HTML5, CSS3 3D transforms, and vanilla JavaScript, this project simulates a real reading experience complete with realistic page-turning physics, responsive controls, and customizable lighting themes.

---

## ✨ Features

* **Realistic 3D Page Turning:** Interactive book animation complete with depth perspective, spine shadows, and smooth page curves.
* **Dual Light & Dark Themes:** Seamlessly toggle between a warm dark aesthetic and a crisp, royal blue light theme using CSS custom properties.
* **Navigation Controls:** 
  * Previous / Next buttons
  * Keyboard arrow key support (`Left Arrow` / `Right Arrow`)
  * Direct page-click flipping
* **Curated Poetry Collection:** Features iconic works by Rabindranath Tagore, Sarojini Naidu, Nissim Ezekiel, Kamala Das, and Sri Aurobindo.
* **Zero External Dependencies:** Built with pure vanilla JavaScript and native CSS—no bulky external libraries required.
